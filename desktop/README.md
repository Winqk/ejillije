# Воздушные барабаны — версия для компьютера

Отдельная программа: без браузера, камера читается напрямую, нейросеть MediaPipe и звук работают локально, поэтому быстрее и с меньшей задержкой, чем веб-версия.

## Установка на Windows (один раз)

1. Распакуйте архив в любую папку, например `Документы\AirDrums`.
2. Дважды щёлкните **`Start Air Drums.bat`**. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».
3. Первый запуск занимает 2–5 минут: при необходимости ставится Python 3.12, затем камера, нейросеть и звук. Нужен интернет.
4. На рабочем столе появится ярлык **«Воздушные барабаны»** — дальше запускайте игру им.

Есть и готовая сборка `AirDrums.exe` без Python: её собирает GitHub Actions (`.github/workflows/desktop-windows.yml`), архив лежит во вкладке Actions → Artifacts.

На macOS и Linux: `python3 -m pip install -r requirements.txt && python3 air_drums.py`.

## Как играть

- Бейте по воздуху сверху вниз — звучит **ближайший** барабан, целиться не нужно. Короткого резкого взмаха кистью достаточно, чем быстрее — тем громче.
- Удар засчитывается в момент, когда рука начинает тормозить; при ударе вспыхивает центр барабана.

## Звук

Рок, джаз и метал звучат **записями настоящих барабанов** из открытых библиотек: Big Rusty Drums, Virtuosity Drums,
Frankensnare (CC0) и DRSKit из DrumGizmo (CC BY 4.0). У каждого удара 3–4 градации силы с вариантами:
слабый взмах звучит мягче по тембру, а не просто тише, и одинаковые удары подряд не повторяются.
Хип-хоп и электроника — синтез в духе TR-808/909. Авторы и лицензии — в [samples/CREDITS.md](samples/CREDITS.md).

## Меню (Esc)

- **Пресеты** — 5 жанров, у каждого свой набор барабанов, звук и стиль (скин):
  - **Рок** — классика: три тома, крэш и райд; красные корпуса, золотые тарелки.
  - **Джаз** — малый со щётками, большой райд; деревянные бочки и тёмная бронза.
  - **Хип-хоп** — пэды драм-машины: бочка 808, хлопок, щелчок, ковбелл.
  - **Электроника** — звук 909 и неоновые барабаны.
  - **Метал** — большая установка: четыре тома, чайна, «щёлкающая» бочка; чёрный лак с красной полосой.
- **Барабаны** — список барабанов набора: прослушать, сменить инструмент (30 звуков), удалить, добавить (до 12), вернуть как в пресете.
  Кнопка «Изменить расстановку» включает редактор прямо на экране.
- **Звук и ритм** — громкость, чувствительность, метроном (темп 40–240, размер 2/4, 3/4, 4/4, 6/8).
- **Вид** — стиль барабанов отдельно от жанра, «Яркие пальцы» (неоновый скелет рук), яркость видео, руки (ИИ) или цветные кончики, полный экран.

Своя расстановка запоминается для каждого жанра отдельно.

## Редактор расстановки (E)

- Клик по барабану — выбрать, тянуть — двигать.
- Голубая ручка сверху — повернуть, ручка «+» сбоку — изменить размер.
- Колёсико мыши — размер, Shift + колёсико или `[` `]` — поворот, стрелки — сдвинуть, Delete — удалить.
- Панель внизу: сменить инструмент (‹ ›), размер (− +), поворот, удалить, добавить, «Готово».

| Клавиша | Действие |
|---|---|
| Esc | меню |
| 1–9 | барабаны с клавиатуры |
| Пробел | бочка |
| Shift (держать) | открытый хай-хэт |
| E | редактор расстановки |
| P | следующий жанр |
| M, ← / → | метроном и темп |
| + / − | чувствительность |
| ↑ / ↓ | громкость |
| Tab | руки (ИИ) / цветные кончики |
| F11 | во весь экран |
| H | подсказка |

**Цветные кончики** — самый точный режим: обмотайте кончики карандашей яркой изолентой (зелёной, розовой, оранжевой), выберите режим в меню «Вид» и кликните по кончику на видео. Правый клик — сбросить цвета.

## Если что-то не так

- **Камера не включается** — закройте Zoom, Teams, браузер с камерой и старую копию игры, затем Меню → Вид → «Перезапустить камеру». Там же можно выбрать другую камеру (на ноутбуках с ИК-камерой для входа по лицу обычная камера может быть «Камерой 2»). Игра сама пробует разные способы подключения; что именно не получилось — видно в журнале.
- **Хочется 60 к/с** — Меню → Вид → «Пробовать 60 к/с». Если после этого камера не включается, игра сама выключит этот режим.
- **Звук трещит** — в том же файле поставьте `"audio_buffer": 512`.
- **Удары срабатывают сами / не срабатывают** — клавиши `+` / `−`.
- Журнал ошибок и заминок: `%APPDATA%\AirDrums\air_drums.log`.
