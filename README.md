# ejillije

## Воздушные барабаны — `drums/`

Веб-приложение: играете по воздуху карандашами или палочками, камера ноутбука и нейросеть превращают удары в звук полной ударной установки (бочка, малый, 3 тома, хай-хэт, крэш, райд).

- **Руки · ИИ** — нейросеть [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker) находит кисти прямо в браузере, ничего настраивать не нужно.
- **Цветные кончики** — точнее: обмотайте кончики палочек яркой изолентой и кликните по ним на видео (можно два разных цвета — по одному на палочку).
- Удар засчитывается, когда рука резко идёт вниз и тормозит. Звучит барабан в точке торможения, громкость зависит от скорости удара.
- `Пробел` — бочка, `Shift` — открытый хай-хэт, `1`–`7` — барабаны с клавиатуры. Есть метроном, а кнопкой «Расставить» барабаны можно перетащить мышью.
- Звук синтезируется Web Audio API, видео никуда не отправляется.

Запуск: откройте `drums/index.html` по https:// (например, через GitHub Pages: `/ejillije/drums/`) или с `localhost`, иначе браузер не даст доступ к камере.
